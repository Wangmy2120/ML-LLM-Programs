## 每题核心思路

1. `主题01_Softmax与掩码.py`：
   softmax 的核心是把分数转成概率分布，先减最大值做数值稳定；mask 的本质是把不该看的位置加上负无穷，经过 softmax 后权重接近 0，因果 mask 就是只能看当前和过去。

2. `主题02_缩放点积注意力.py`：
   输入 Q、K、V，先算相似度 `QK^T`，再除以 `sqrt(d_k)` 防止分数过大导致梯度不稳定，然后做 mask、softmax 得到注意力权重，最后和 V 加权求和得到输出。

3. `主题03_多头注意力.py`：
   多头注意力就是把大维度拆成多个头并行做注意力，每个头学不同子空间特征，最后再拼接回去；好处是表达能力更强，同时保持每个头的计算可控。

4. `主题04_位置编码.py`：
   Transformer 本身不带顺序感，需要位置编码补充位置信息；经典正弦位置编码是偶数维用 sin、奇数维用 cos，通过不同频率让模型同时感知局部和长程位置关系。

5. `主题05_前馈网络.py`：
   FFN 对每个 token 独立做两层 MLP，常见是先升维、激活、再降维；它不做 token 间交互，主要负责 token 内部的非线性特征变换。

6. `主题06_LayerNorm与残差连接.py`：
   LayerNorm 在单个 token 的特征维上做归一化，稳定训练；残差连接是 `x + sublayer(x)`，保留原信息并改善梯度传播，Pre-LN 结构在大模型里很常见。

7. `主题07_Transformer块.py`：
   一个标准块可以概括为两段：先注意力再 FFN，每段都配 Add&Norm；注意力负责 token 间信息交互，FFN 负责 token 内变换，二者串起来构成 Transformer 主干。

8. `主题08_KV缓存.py`：
   自回归推理时历史 token 的 K/V 不需要重复计算，缓存后每步只算新 token 的 Q，再和缓存的 K/V 做注意力，从“整句重算”变成“增量计算”，显著降低延迟。

9. `主题09_线性回归.py`：
   线性回归假设 `y = wx + b`，用 MSE 衡量误差，通过梯度下降迭代更新 w、b，让预测值逐步逼近真实值，是最基础的监督学习优化范式。

10. `主题10_KMeans.py`：
    K-Means 是无监督聚类，循环两步直到收敛：先按最近中心分配样本，再按簇内均值更新中心；本质是在最小化样本到所属中心的平方距离。

11. `主题11_MHA与GQA.py`：
    MHA 是每个 Q 头对应一组 K/V 头；GQA 则让多个 Q 头共享同一个 K/V 头，基本保留效果的同时显著降低 KV cache 开销，常用于大模型推理加速。

12. `主题12_LoRA.py`：
    LoRA 冻结原权重 W，只训练低秩增量 `DeltaW = B@A`，前向时用 `W + alpha/r * DeltaW`；核心价值是以极少参数完成高效微调，显存和训练成本更低。

13. `主题13_LN与RMSNorm.py`：
    LN 会减均值再归一化，RMSNorm 只按均方根缩放不减均值；RMSNorm 计算更简洁，在一些大模型中更稳定且速度更友好。

14. `主题14_熵KL交叉熵.py`：
    熵衡量分布自身不确定性，KL 衡量用 Q 近似 P 的信息损失，交叉熵可拆成 `H(P)+KL(P||Q)`；分类训练最小化交叉熵，本质上是在逼近真实分布。

15. `主题15_PPO.py`：
    PPO 用概率比值 `ratio` 衡量新旧策略变化，并用 clip 截断过大更新，目标函数取裁剪前后较小值，核心是“稳步更新策略，避免训练震荡”。

16. `主题16_DPO.py`：
    DPO 直接用偏好对 `(chosen, rejected)` 训练，不显式训练奖励模型；它优化策略与参考模型在偏好差值上的相对优势，让模型更倾向生成人类偏好的回答。
